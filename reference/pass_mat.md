# Presence-absence matrix of Australian passeriformes

This is a presence-absence matrix for passeriformes obtained from
Australian grid-cells. Each column represents a specific passeriforme
species, while each row corresponds to an assemblage (or grid cell)
within the Australian grid-map. All passerine range maps were sourced
from the BirdLife platform.

## Usage

``` r
pass_mat
```

## Format

Matrix

## Source

<https://www.birdlife.org/>
