# Package index

## All functions

- [`AU_adj`](https://araujomat.github.io/treesliceR/reference/AU_adj.md)
  : Adjacency matrix for focal and adjacent assemblages
- [`AU_grid`](https://araujomat.github.io/treesliceR/reference/AU_grid.md)
  : Australia grid map
- [`CpB()`](https://araujomat.github.io/treesliceR/reference/CpB.md) :
  Calculates the rate of accumulation of phylogenetic B-diversity (CpB)
  over time slices
- [`CpB_RW()`](https://araujomat.github.io/treesliceR/reference/CpB_RW.md)
  : Calculates the range weighted rate of accumulation of phylogenetic
  B-diversity (CpB_RW) over time slices
- [`CpD()`](https://araujomat.github.io/treesliceR/reference/CpD.md) :
  Calculates the rate of accumulation of phylogenetic diversity (CpD)
  over time slices
- [`CpE()`](https://araujomat.github.io/treesliceR/reference/CpE.md) :
  Calculates the rate of accumulation of phylogenetic endemism (CpE)
  over time slices
- [`CpR_graph()`](https://araujomat.github.io/treesliceR/reference/CpR_graph.md)
  : Make a line graph or a grid map of estimated rates of accumulation
  of a given phylogenetic index.
- [`CpR_sensitivity()`](https://araujomat.github.io/treesliceR/reference/CpR_sensitivity.md)
  : Runs a sensitivity analysis for rates of accumulation of a given
  phylogenetic index
- [`CpR_sensitivity_plot()`](https://araujomat.github.io/treesliceR/reference/CpR_sensitivity_plot.md)
  : Make a plot of the sensitivity analysis evaluated under cumulative
  phylogenetic rate functions
- [`nodes_config()`](https://araujomat.github.io/treesliceR/reference/nodes_config.md)
  : Capture general branching information for an inputted phylogenetic
  tree
- [`pass_mat`](https://araujomat.github.io/treesliceR/reference/pass_mat.md)
  : Presence-absence matrix of Australian passeriformes
- [`pass_trees`](https://araujomat.github.io/treesliceR/reference/pass_trees.md)
  : Phylogenetic tree of passerines from Australia
- [`phylo_pieces()`](https://araujomat.github.io/treesliceR/reference/phylo_pieces.md)
  : Slices a phylogenetic tree into multiple temporal slices
- [`prune_tips()`](https://araujomat.github.io/treesliceR/reference/prune_tips.md)
  : Collapse the tips of a phylogenetic tree based on a temporal
  threshold
- [`r_phylo()`](https://araujomat.github.io/treesliceR/reference/r_phylo.md)
  : Calculates the relative value of a phylogenetic index in a temporal
  sequence of phylogenetic slices.
- [`squeeze_int()`](https://araujomat.github.io/treesliceR/reference/squeeze_int.md)
  : Slices a temporal interval within a phylogenetic tree
- [`squeeze_root()`](https://araujomat.github.io/treesliceR/reference/squeeze_root.md)
  : Slices a phylogenetic tree following a 'rootward' orientation
- [`squeeze_tips()`](https://araujomat.github.io/treesliceR/reference/squeeze_tips.md)
  : Slices a phylogenetic tree following a 'tipward' orientation
